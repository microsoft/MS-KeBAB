This folder contains examples of computing metrics for various tasks.

# Extraction

[extraction/basic_example/run.py](extraction/basic_example/run.py) demonstrates how to extract entity fragments from text and evaluate them on the test data

[extraction/adding_new_task/run.py](extraction/adding_new_task/run.py) demonstrates how to add new entity extraction task to the benchmark and change its configuration

# Linking

[linking/linking_metrics_example.py](linking/linking_metrics_example.py) demonstrates how to train your own linker on the training data and evaluate it on the test data.
